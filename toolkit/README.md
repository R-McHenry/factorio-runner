# toolkit

`fkcore/` is Rory's fk toolkit, 3.1.2 (v5 main `bc6c1cb`, 2026-11-08; `git archive` of `fkcore`),
for the runner's `fk` tool profile. The codebase's `docs/` (START.md, EXAMPLES.md, LANGUAGE.md,
TOOLKIT.md, BUILDING.md, examples/) are the same release's `agent/docs`. Before 11-08 it was 2.1.30
copied from factorio-playable `game/seablock/kit/fkcore`. `make_pack.py` builds the
`sa-early` pack (Space Age plus the fk-early-bots mod) in `fkcore/data/packs/sa-early/`.
